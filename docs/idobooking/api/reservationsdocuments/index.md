# Bramka Reservations Documents

Źródło: [iDoBooking](https://api.idobooking.com/pl/developers/api/administration-panel-api/?action=documentation&function=reservationsdocuments)

Kopia: 24.10.2026. [Pełny zrzut](index.jpg).

Dokumentacja API Booking 

 
 
 
 
 
 
 

Umożliwia zarządzanie dokumentami do rezerwacji 
 
 
 

### Dostępne metody:

 
 
 [cancelDocuments](cancelDocuments.html) Metoda pozwala na anulowanie dokumentów do rezerwacji. 
 
 
 
 [createDocuments](createDocuments.html) Metoda pozwala na wystawienie dokumentów do rezerwacji. 
 
 
 
 [editDocuments](editDocuments.html) Metoda pozwala na edytowanie dokumentów do rezerwacji. 
 
 
 
 [getDocuments](getDocuments.html) Metoda pozwala na pobranie informacji o dokumentach wystawionych do rezerwacji w panelu administracyjnym.
