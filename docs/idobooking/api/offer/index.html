Dokumentacja API Booking

Umożliwia pobieranie informacji na temat cen i dostępności dla przedmiotów rezerwacji na każdy dzień

Dostępne metody:

getAvailabilityAndPricesForDays Pobiera ceny oraz dostępność dla obiektów na każdy dzień.
getAvailabilityForDays Pobiera dostępność dla obiektów na każdy dzień.
getChildrenInformation Pobiera informacje o zdefiniowanych przedziałach wiekowych dzieci.
getPricesForDays Pobiera ceny dla przedmiotów rezerwacji na każdy dzień.
getPricesForDaysForObject Pobiera ceny dla przedmiotu rezerwacji na każdy dzień z uwzględnieniem różnych kombinacji dzieci i dorosłych.
