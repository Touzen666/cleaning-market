# Bramka Offer

Źródło: [iDoBooking](https://api.idobooking.com/pl/developers/api/administration-panel-api/?action=documentation&function=offer)

Kopia: 24.10.2026. [Pełny zrzut](index.jpg).

Dokumentacja API Booking 

 
 
 
 
 
 
 

Umożliwia pobieranie informacji na temat cen i dostępności dla przedmiotów rezerwacji na każdy dzień 
 
 
 

### Dostępne metody:

 
 
 [getAvailabilityAndPricesForDays](getAvailabilityAndPricesForDays.html) Pobiera ceny oraz dostępność dla obiektów na każdy dzień. 
 
 
 
 [getAvailabilityForDays](getAvailabilityForDays.html) Pobiera dostępność dla obiektów na każdy dzień. 
 
 
 
 [getChildrenInformation](getChildrenInformation.html) Pobiera informacje o zdefiniowanych przedziałach wiekowych dzieci. 
 
 
 
 [getPricesForDays](getPricesForDays.html) Pobiera ceny dla przedmiotów rezerwacji na każdy dzień. 
 
 
 
 [getPricesForDaysForObject](getPricesForDaysForObject.html) Pobiera ceny dla przedmiotu rezerwacji na każdy dzień z uwzględnieniem różnych kombinacji dzieci i dorosłych.
