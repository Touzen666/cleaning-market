# Bramka Clients

Źródło: [iDoBooking](https://api.idobooking.com/pl/developers/api/administration-panel-api/?action=documentation&function=clients)

Kopia: 24.10.2026. [Pełny zrzut](index.jpg).

Dokumentacja API Booking 

 
 
 
 
 
 
 

Umożliwia dowolne zarządzanie bazą klientów i przypisanych do nich gości, co pozwala także m.in. na integrację z zewnętrznymi narzędziami CRM, czy systemami marketingowymi. 
 
 
 

### Dostępne metody:

 
 
 [add](add.html) Dodaje klientów oraz powiązanych z kontem gości upoważnionych do odbioru rezerwacji. 
 
 
 
 [delete](delete.html) Usuwa klientów oraz powiązane z kontem dane gości. 
 
 
 
 [edit](edit.html) Edytuje dane klienta i jego gości. 
 
 
 
 [get](get.html) Pobiera informacje o kliencie i jego gościach. 
 
 
 
 [history](history.html) Pobiera historię zmian danych klienta.
