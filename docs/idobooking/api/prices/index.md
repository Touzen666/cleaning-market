 Dokumentacja API Booking 

 
 
 
 
 
 
 

Umożliwia zarządzanie cenami w poszczególnych kanałach sprzedaży. 
 
 
 

### Dostępne metody:

 
 
 [deleteExceptions](deleteExceptions.html) Usuwa nadpisaną cenę i przywraca cenę sprzed modyfikacji. 
 
 
 
 [getExceptions](getExceptions.html) Pobiera listę nadpisanych cen w podanych źródłach rezerwacji, we wskazanych przedmiotach rezerwacji. 
 
 
 
 [setExceptions](setExceptions.html) Nadpisuje dotychczasową cenę nową wartością.
