Dokumentacja API Booking

Umożliwia zarządzanie płatnościami w rezerwacjach

Dostępne metody:

add Metoda pozwala na dodawanie wpłat do rezerwacji.
cancel Metoda pozwala na anulację wpłat dla rezerwacji.
confirm Metoda pozwala na potwiedzenie wpłat dla rezerwacji.
edit Metoda pozwala na edytowanie wpłat dla rezerwacji.
get Metoda pozwala na pobieranie wpłat dla rezerwacji.
getPaymentForms Metoda pozwala na pobranie listy form płatności dostępnych w panelu administracyjnym.
