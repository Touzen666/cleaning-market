# Bramka Payments

Źródło: [iDoBooking](https://api.idobooking.com/pl/developers/api/administration-panel-api/?action=documentation&function=payments)

Kopia: 24.10.2026. [Pełny zrzut](index.jpg).

Dokumentacja API Booking 

 
 
 
 
 
 
 

Umożliwia zarządzanie płatnościami w rezerwacjach 
 
 
 

### Dostępne metody:

 
 
 [add](add.html) Metoda pozwala na dodawanie wpłat do rezerwacji. 
 
 
 
 [cancel](cancel.html) Metoda pozwala na anulację wpłat dla rezerwacji. 
 
 
 
 [confirm](confirm.html) Metoda pozwala na potwiedzenie wpłat dla rezerwacji. 
 
 
 
 [edit](edit.html) Metoda pozwala na edytowanie wpłat dla rezerwacji. 
 
 
 
 [get](get.html) Metoda pozwala na pobieranie wpłat dla rezerwacji. 
 
 
 
 [getPaymentForms](getPaymentForms.html) Metoda pozwala na pobranie listy form płatności dostępnych w panelu administracyjnym.
