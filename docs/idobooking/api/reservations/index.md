# Bramka Reservations

Źródło: [iDoBooking](https://api.idobooking.com/pl/developers/api/administration-panel-api/?action=documentation&function=reservations)

Kopia: 24.10.2026. [Pełny zrzut](index.jpg).

Dokumentacja API Booking 

 
 
 
 
 
 
 

Bramka służy do pobierania informacji o złożonych rezerwacjach. 
 
 
 

### Dostępne metody:

 
 
 [add](add.html) Dodaje rezerwacje. 
 
 
 
 [changeCurrency](changeCurrency.html) Pozwala na zmianę waluty w rezerwacji. 
 
 
 
 [edit](edit.html) Edytuje rezerwacje. 
 
 
 
 [editStatus](editStatus.html) Edytuje status rezerwacji. 
 
 
 
 [get](get.html) Zwraca informację o rezerwacjach. 
 
 
 
 [getSources](getSources.html) Zwraca źródła rezerwacji. 
 
 
 
 [notifyClient](notifyClient.html) Wysyła wiadomość do klienta odnośnie rezerwacji. 
 
 
 
 [notifyExternalService](notifyExternalService.html) Wysyła informację do serwisu zewnętrznego. 
 
 
 
 [setDiscount](setDiscount.html) Pozwala na ustawienie rabatu dla rezerwacji.
