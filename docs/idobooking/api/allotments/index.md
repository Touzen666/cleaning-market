Bramka służy do ustawiania dostępności sprzedaży 
 
 
 

### Dostępne metody:

 
 
 [deleteExceptions](deleteExceptions.html) Usuwa nadpisaną dostępność i przywraca dostępność sprzed modyfikacji. 
 
 
 
 [getExceptions](getExceptions.html) Pobiera listę nadpisywanych dostępności. 
 
 
 
 [setExceptions](setExceptions.html) Nadpisuje dostępność przedmiotu rezerwacji. 
 
 
 
 [sources](sources.html) Zwraca listę dostępnych źródeł rezerwacji.
