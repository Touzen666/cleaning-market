# Bramka Amenities

Źródło: [iDoBooking](https://api.idobooking.com/pl/developers/api/administration-panel-api/?action=documentation&function=amenities)

Kopia: 24.10.2026. [Pełny zrzut](index.jpg).

Dokumentacja API Booking 

 
 
 
 
 
 
 

Umożliwia pobranie listy udogodnień możliwych do przypisania w przedmiotach rezerwacji oraz w dodatkach. 
 
 
 

### Dostępne metody:

 
 
 [getForAddons](getForAddons.html) Pobiera udogodnienia możliwe do przypisania dla dodatków typu posiłek lub parking. Udogodnienia te są wymagane do ustawienia w bramce Addons. Wpływają one na atrakcyjność oferty i spójność danych przekazywanych do serwisów zewnętrznych. 
 
 
 
 [getForObjects](getForObjects.html) Pobiera udogodnienia możliwe do przypisania dla wybranych typów przedmiotów rezerwacji.
