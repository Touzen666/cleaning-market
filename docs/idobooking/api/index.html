Dokumentacja API Booking

Dostępne bramki:

Allotment

Bramka służy do ustawiania dostępności sprzedaży

Amenities

Umożliwia pobranie listy udogodnień możliwych do przypisania w przedmiotach rezerwacji oraz w dodatkach.

Availability Locks

Bramka służy do pobierania informacji o blokadach dostępności.

Clients

Umożliwia dowolne zarządzanie bazą klientów i przypisanych do nich gości, co pozwala także m.in. na integrację z zewnętrznymi narzędziami CRM, czy systemami marketingowymi.

Locks

Umożliwia zarządzanie kodami zamków elektronicznych

Objects

Umożliwia zarządzanie bazą przedmiotów rezerwacji oraz ich właściwościami.

Offer

Umożliwia pobieranie informacji na temat cen i dostępności dla przedmiotów rezerwacji na każdy dzień

Payments

Umożliwia zarządzanie płatnościami w rezerwacjach

Prices

Umożliwia zarządzanie cenami w poszczególnych kanałach sprzedaży.

Public

Bramka publiczna, niewymagająca danych do logowania.

Reservations

Bramka służy do pobierania informacji o złożonych rezerwacjach.

Reservations Documents

Umożliwia zarządzanie dokumentami do rezerwacji

Restrictions

Bramka służy do zarządzania wyjątkami od restrykcji pobytu

Users

Umożliwia zarządzanie bazą użytkowników oraz nadawanie im uprawnień do panelu, powiadomień e-mail oraz komunikatów.
